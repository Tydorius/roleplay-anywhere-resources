# Roleplay Anywhere resources

Community resources for Anywhere RPG (Roleplay Anywhere).

| Folder | What it is |
|---|---|
| [`mods/better-images`](mods/better-images) | ComfyUI image-generation mod packs (Flux.2 klein, Flux.1, Qwen-Image, SDXL, SD1.5) with background removal for map objects and items, a setup script that adapts them to your ComfyUI's model files, and an Image Gallery page for viewing and regenerating any scenario image. |
